# Student Election Registration System

This is a mini project developed using PHP and MySQL.

## Features
- Student Registration for Election
- Select Department and Election Post
- View Registered Students
- Clean and Modern UI

## Technologies Used
- PHP
- MySQL
- HTML
- CSS

## How to Run
1. Install XAMPP
2. Start Apache and MySQL
3. Place project folder inside htdocs
4. Import database using phpMyAdmin
5. Run using http://localhost/student_election/register.php

## Note
This project cannot run directly on GitHub Pages because it requires PHP and MySQL.
